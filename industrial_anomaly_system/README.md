# 工业设备故障诊断与边缘预警系统

基于「云边协同」的工业设备预测性维护 Demo：边缘端轻量模型快速初筛，云端做残差诊断与历史故障溯源，前端看板做可视化联动。

## 目录结构

```
industrial_anomaly_system/
├── requirements.txt          # 项目依赖包
├── main.py                   # 核心业务串联（数据流转、云边协同模拟）
├── core/
│   ├── __init__.py
│   ├── data_processor.py     # 数据清洗（区分快慢变量）与连续性异常检测
│   └── algorithms.py         # 算法库（感知机、降维KNN、自适应多元回归）
├── database/
│   └── schema.sql            # MySQL 建表、索引、视图与冷热分离设计
└── frontend/
    ├── index.html            # 页面骨架（含溯源卡片）
    ├── style.css             # 工业暗黑风样式
    ├── app.js                # ECharts 渲染与事件联动
    └── data.json             # 由 main.py 自动生成（推理结果）
```

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 跑一遍数据流水线，生成 frontend/data.json
python main.py

# 3. 启动本地服务（必须走 HTTP，file:// 下浏览器禁止 fetch 本地 JSON）
python -m http.server 8000

# 4. 浏览器访问
http://localhost:8000/frontend/index.html
```

数据库部分（可选）：`mysql -u root -p < database/schema.sql`

## 数据流设计

```
模拟采集(1s/点)
   │
   ├─ 慢变量（温度）→ 滑窗 IQR 截断 + 边界 Smooth
   └─ 快变量（振动）→ 中值滤波去噪，残差超 3σ 的尖峰保留（真实冲击不抹掉）
   │
   ├─ 边缘端：感知机（温度, 振动）二分类初筛 → 只把可疑窗口上传（省带宽）
   │
   ├─ 云端：温度 = f(振动) 多元回归 → 残差 |y-ŷ| > 3σ 自适应阈值 → 判异
   │        阈值每 30 点用"干净"近期残差重估（仅当窗口内告警 <3 个），跟随工况漂移
   │
   ├─ 云端：PCA(2) 降维 + KNN(k=3) 检索历史故障库 → 最近邻距离 + 诊断建议
   │
   └─ 导出 frontend/data.json → ECharts 看板点击联动溯源卡片
```

## 关键设计点（面试可讲）

| 设计 | 解决什么问题 |
| --- | --- |
| 快慢变量差异化清洗 | 统一滤波会把振动的冲击特征抹平，导致早期点蚀漏报 |
| 连续性异常检测 | 单点越阈值多为噪声，连续 N 点越界才报，降低误报率 |
| 边缘感知机 + 云端重模型 | 带宽与算力分层：边缘秒级响应，云端只处理可疑样本 |
| PCA + KNN | 多维特征下欧氏距离失效（维度灾难），先降维再检索 |
| 自适应 3σ 阈值 | 概念漂移：环境温度/负载缓慢变化会让固定阈值失效 |
| 冷热分离 | 热表只留 7 天保证看板查询快，冷表按月分表供离线训练，过期直接 DROP |
| 联合索引 (machine_id, record_time) | 覆盖"按设备+时间范围"的高频查询，避免回表与 filesort |
